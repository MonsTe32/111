# Companion Mod (NeoForge 1.21.1)

## Збірка jar
Варіант 1 (на ПК): встанови Java 21 + Gradle 8.10+, у папці проєкту виконай `gradle build`.
Готовий мод: build/libs/companionmod-1.0.0.jar -> кинь у папку mods.

Варіант 2 (без встановлення нічого): завантаж проєкт на GitHub (новий репозиторій), перейди у
вкладку Actions -> Build mod -> після завершення завантаж артефакт companionmod-jar.

## Гра
Крафт: 2 маки + 2 золоті злитки + алмаз (Серце-амулет). ПКМ по блоку, щоб призвати.
ПКМ порожньою рукою - поговорити. Shift+ПКМ - сісти/йти. Квіти - подарунки. Їжа - лікує.
Броня/зброя - вдягає. Вночі біля вогнища або під зорями вона розповідає особливі сцени.
